# MainAPI: Антифрод + Система маршрутизации платежей

## О проекте

**MainAPI** — это учебный проект, разработанный для выполнения практического задания от компании **ClickMedia**. Его основная цель — объединить в себе две ключевые функции:

1.  **Антифрод-система**: анализ и выявление подозрительных транзакций для предотвращения мошенничества.
2.  **Система маршрутизации платежей**: интеллектуальный выбор оптимального платежного провайдера (из представленных: ProviderA, ProviderB, ProviderC) на основе заданных правил и приоритетов.

В процессе работы над проектом были изучены базовые принципы построения антифрод-систем и получен ценный практический опыт интеграции различных сервисов.

## Стек технологий

*   **Backend**: C#, .NET (веб-фреймворк)
*   **База данных**: PostgreSQL
*   **Контейнеризация**: Docker, Docker Compose
*   **Фронтенд (демо-интерфейс)**: HTML, CSS, JavaScript (папка `web`)

## Структура проекта

*   `Application/` — содержит бизнес-логику и сервисы приложения.
*   `Domain/` — включает модели данных и основные сущности предметной области.
*   `Infrastructure/` — ответственен за работу с внешними ресурсами (база данных, HTTP-клиенты для провайдеров).
*   `MainAPI/` — главный веб-проект (контроллеры, настройка middleware, конфигурация).
*   `ProviderA/`, `ProviderB/`, `ProviderC/` — симуляции внешних платежных шлюзов.
*   `mainapi/Controllers/` — REST-контроллеры API.
*   `web/` — статический HTML-клиент для демонстрации работы системы.
*   `docker-compose.yml` — файл для оркестрации всех контейнеров.
*   `.env` — файл с переменными окружения.

## Инструкция по запуску

### Предварительные требования

*   Установленный Docker и Docker Compose на вашем компьютере.

### Шаги для запуска

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Qusyl/MainAPI.git
    cd MainAPI


2. **Перейти в папку проекта ( где расположен docker-compose.yml )**
3. **Запустить или убедиться, что докер установлен и готов к работе**
4. **Выполнить команду docker-compose up --build**
5. **Дождаться завершения деплоинга**
6. **Перейти в папку web**
7. **Зайти на сайт index.html**
8. **Для просмотра БД выполнить команду Docker exec -it main-db psql -U postgres -d postgres**

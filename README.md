======================= О проекте =======================
Данный проект создан для выполнения практического задания от компании ClickMedia.
Задание : 
Антифрод + Система маршрутизации платежей
Объединяет в себе антифрод систему и выбора платежного провайдера


======================= Инструкция по запуску =======================
Для запуска необходимо:
1) Перейти в папку проекта ( где расположен docker-compose.yml )
2) Запустить или убедиться, что докер установлен и готов к работе
3) Выполнить команду docker-compose up --build
4) Дождаться завершения деплоинга
5) Перейти в папку web
6) Зайти на сайт index.html
